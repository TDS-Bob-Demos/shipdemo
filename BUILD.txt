SHIPPING DEMO - BUILD COMMANDS (PUB400, library ANNIEROME2)
=============================================================

STEP 0 - Library list (do this in every new 5250 session / Bob terminal)
-------------------------------------------------------------------------
CHGCURLIB CURLIB(ANNIEROME2)
ADDLIBLE LIB(ANNIEROME2)        (ignore "already in library list")

STEP 1 - Source files (ignore CPF5813 "already exists")
--------------------------------------------------------
CRTSRCPF FILE(ANNIEROME2/QDDSSRC)   RCDLEN(112)
CRTSRCPF FILE(ANNIEROME2/QRPGLESRC) RCDLEN(112)
CRTSRCPF FILE(ANNIEROME2/QCLLESRC)  RCDLEN(112)
CRTSRCPF FILE(ANNIEROME2/QSQLSRC)   RCDLEN(112)

STEP 2 - Get the source into members
-------------------------------------
Option A (easiest in Bob): in the Object Browser, right-click each source
file > New member, name it as below, paste the file contents, save.

Option B: upload the whole folder to the IFS at /home/ANNIEROME/shipdemo
(drag and drop in Bob's IFS Browser), then run:

CPYFRMSTMF FROMSTMF('/home/ANNIEROME/shipdemo/SHPITEM.pf')   TOMBR('/QSYS.LIB/ANNIEROME2.LIB/QDDSSRC.FILE/SHPITEM.MBR')   MBROPT(*REPLACE)
CPYFRMSTMF FROMSTMF('/home/ANNIEROME/shipdemo/SHPMTR.pf')    TOMBR('/QSYS.LIB/ANNIEROME2.LIB/QDDSSRC.FILE/SHPMTR.MBR')    MBROPT(*REPLACE)
CPYFRMSTMF FROMSTMF('/home/ANNIEROME/shipdemo/SHPORDH.pf')   TOMBR('/QSYS.LIB/ANNIEROME2.LIB/QDDSSRC.FILE/SHPORDH.MBR')   MBROPT(*REPLACE)
CPYFRMSTMF FROMSTMF('/home/ANNIEROME/shipdemo/SHPORDD.pf')   TOMBR('/QSYS.LIB/ANNIEROME2.LIB/QDDSSRC.FILE/SHPORDD.MBR')   MBROPT(*REPLACE)
CPYFRMSTMF FROMSTMF('/home/ANNIEROME/shipdemo/SHPLOAD.pf')   TOMBR('/QSYS.LIB/ANNIEROME2.LIB/QDDSSRC.FILE/SHPLOAD.MBR')   MBROPT(*REPLACE)
CPYFRMSTMF FROMSTMF('/home/ANNIEROME/shipdemo/SHPORDL1.lf')  TOMBR('/QSYS.LIB/ANNIEROME2.LIB/QDDSSRC.FILE/SHPORDL1.MBR')  MBROPT(*REPLACE)
CPYFRMSTMF FROMSTMF('/home/ANNIEROME/shipdemo/SHPCONFD.dspf') TOMBR('/QSYS.LIB/ANNIEROME2.LIB/QDDSSRC.FILE/SHPCONFD.MBR') MBROPT(*REPLACE)
CPYFRMSTMF FROMSTMF('/home/ANNIEROME/shipdemo/SHPWGT.rpgle')  TOMBR('/QSYS.LIB/ANNIEROME2.LIB/QRPGLESRC.FILE/SHPWGT.MBR')  MBROPT(*REPLACE)
CPYFRMSTMF FROMSTMF('/home/ANNIEROME/shipdemo/SHPWGTFX.rpgle') TOMBR('/QSYS.LIB/ANNIEROME2.LIB/QRPGLESRC.FILE/SHPWGTFX.MBR') MBROPT(*REPLACE)
CPYFRMSTMF FROMSTMF('/home/ANNIEROME/shipdemo/SHPVAL.rpgle')  TOMBR('/QSYS.LIB/ANNIEROME2.LIB/QRPGLESRC.FILE/SHPVAL.MBR')  MBROPT(*REPLACE)
CPYFRMSTMF FROMSTMF('/home/ANNIEROME/shipdemo/SHPCONF.clle')  TOMBR('/QSYS.LIB/ANNIEROME2.LIB/QCLLESRC.FILE/SHPCONF.MBR')  MBROPT(*REPLACE)
CPYFRMSTMF FROMSTMF('/home/ANNIEROME/shipdemo/SHPDATA.sql')   TOMBR('/QSYS.LIB/ANNIEROME2.LIB/QSQLSRC.FILE/SHPDATA.MBR')   MBROPT(*REPLACE)
CPYFRMSTMF FROMSTMF('/home/ANNIEROME/shipdemo/SHPRESET.sql')  TOMBR('/QSYS.LIB/ANNIEROME2.LIB/QSQLSRC.FILE/SHPRESET.MBR')  MBROPT(*REPLACE)

Then set member types so Bob colors/parses them correctly:
CHGPFM FILE(ANNIEROME2/QDDSSRC)   MBR(SHPITEM)  SRCTYPE(PF)
CHGPFM FILE(ANNIEROME2/QDDSSRC)   MBR(SHPMTR)   SRCTYPE(PF)
CHGPFM FILE(ANNIEROME2/QDDSSRC)   MBR(SHPORDH)  SRCTYPE(PF)
CHGPFM FILE(ANNIEROME2/QDDSSRC)   MBR(SHPORDD)  SRCTYPE(PF)
CHGPFM FILE(ANNIEROME2/QDDSSRC)   MBR(SHPLOAD)  SRCTYPE(PF)
CHGPFM FILE(ANNIEROME2/QDDSSRC)   MBR(SHPORDL1) SRCTYPE(LF)
CHGPFM FILE(ANNIEROME2/QDDSSRC)   MBR(SHPCONFD) SRCTYPE(DSPF)
CHGPFM FILE(ANNIEROME2/QRPGLESRC) MBR(SHPWGT)   SRCTYPE(RPGLE)
CHGPFM FILE(ANNIEROME2/QRPGLESRC) MBR(SHPWGTFX) SRCTYPE(RPGLE)
CHGPFM FILE(ANNIEROME2/QRPGLESRC) MBR(SHPVAL)   SRCTYPE(RPGLE)
CHGPFM FILE(ANNIEROME2/QCLLESRC)  MBR(SHPCONF)  SRCTYPE(CLLE)
CHGPFM FILE(ANNIEROME2/QSQLSRC)   MBR(SHPDATA)  SRCTYPE(SQL)
CHGPFM FILE(ANNIEROME2/QSQLSRC)   MBR(SHPRESET) SRCTYPE(SQL)

STEP 3 - Create files (order matters: PFs, then LF)
---------------------------------------------------
CRTPF FILE(ANNIEROME2/SHPITEM) SRCFILE(ANNIEROME2/QDDSSRC)
CRTPF FILE(ANNIEROME2/SHPMTR)  SRCFILE(ANNIEROME2/QDDSSRC)
CRTPF FILE(ANNIEROME2/SHPORDH) SRCFILE(ANNIEROME2/QDDSSRC)
CRTPF FILE(ANNIEROME2/SHPORDD) SRCFILE(ANNIEROME2/QDDSSRC)
CRTPF FILE(ANNIEROME2/SHPLOAD) SRCFILE(ANNIEROME2/QDDSSRC)
CRTLF FILE(ANNIEROME2/SHPORDL1) SRCFILE(ANNIEROME2/QDDSSRC)
CRTDSPF FILE(ANNIEROME2/SHPCONFD) SRCFILE(ANNIEROME2/QDDSSRC)

STEP 4 - Load sample data
-------------------------
RUNSQLSTM SRCFILE(ANNIEROME2/QSQLSRC) SRCMBR(SHPDATA) COMMIT(*NONE)

STEP 5 - Compile programs (callee first) - compile the BUGGY SHPWGT
-------------------------------------------------------------------
CRTBNDRPG PGM(ANNIEROME2/SHPWGT) SRCFILE(ANNIEROME2/QRPGLESRC) SRCMBR(SHPWGT) DBGVIEW(*SOURCE)
CRTBNDRPG PGM(ANNIEROME2/SHPVAL) SRCFILE(ANNIEROME2/QRPGLESRC) SRCMBR(SHPVAL) DBGVIEW(*SOURCE)
CRTBNDCL  PGM(ANNIEROME2/SHPCONF) SRCFILE(ANNIEROME2/QCLLESRC) SRCMBR(SHPCONF) DBGVIEW(*SOURCE)

Do NOT compile SHPWGTFX. It is your backup copy of the fix.

STEP 6 - Smoke test
-------------------
CALL ANNIEROME2/SHPCONF
  Load 14 -> HELD (red), weight 149,021 (the bug)
  Load 15 -> RELEASED (green), weight 11,634
  Load 16 -> HELD, "NO MTR ON FILE FOR HEAT H24-6118" (a real hold, not a bug)
F3 to exit.

BEFORE EACH DEMO RUN (reset)
----------------------------
RUNSQLSTM SRCFILE(ANNIEROME2/QSQLSRC) SRCMBR(SHPRESET) COMMIT(*NONE)
CRTBNDRPG PGM(ANNIEROME2/SHPWGT) SRCFILE(ANNIEROME2/QRPGLESRC) SRCMBR(SHPWGT) DBGVIEW(*SOURCE)
   (only needed if you saved Bob's fix into the SHPWGT member - restore the
    buggy source first, e.g. re-run the CPYFRMSTMF for SHPWGT.rpgle)

EMERGENCY FIX DURING THE DEMO (if Bob's edit misbehaves)
--------------------------------------------------------
CRTBNDRPG PGM(ANNIEROME2/SHPWGT) SRCFILE(ANNIEROME2/QRPGLESRC) SRCMBR(SHPWGTFX) DBGVIEW(*SOURCE)
